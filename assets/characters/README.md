# Character art

Low-poly character renders for the 3D town. Each file shows one character, named `<character>-<view>.png`.
Views: `front`, `side-left` (character faces left), `side-right` (character faces right), `back`.
Sizes vary: most side and back views are 1024×1536; most front views are 307×512 crops from the ten-character sheet (Meena's front is 1024×1536); left-facing views for Sethu, Meena, Sakthivel, Sivaram, Devan and Arul are 250×1024 crops from a six-character sheet. All sit on a flat grey background (no transparency yet).
