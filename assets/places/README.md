# Place art

Concept images for the Case 1 locations, one per place. Each file is named after its place id in `cases/case-01-harbor-ledger/town.json`, or after the group of places it covers.

| File | Places |
| --- | --- |
| `crane-shipping.png` | Crane Shipping |
| `detectives-office.png` | Detective's office |
| `dock-camera-posts.png` | Dock and camera posts (Lead 2) |
| `fish-hall.png` | Fish hall (Lead 1) |
| `harbor-office.png` | Harbor office (Lead 4) |
| `ice-house-net-loft-boathouse.png` | Ice house, net loft, boathouse |
| `warehouse-9.png` | Warehouse 9 |

These are isometric concept art, not 3D models. They guide the scene build and are not loaded by the game.
